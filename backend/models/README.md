# Model and data files

This folder is ignored by Git because the generated model/data files are too large for a normal GitHub push.

Place the required local files here before running the backend:

- `features.npy`
- `final_dataset.csv`
- `image_labels.npy`
- `lastcleaned_data.csv`
- `logistic_model.pkl`
- `model.pkl`
- `products_processed.csv`
- `tfidf_vectorizer.pkl`
- `valid_paths.npy`
- `vectorizer.pkl`

For production hosting, upload these files separately, use Git LFS, or download them during deployment from external storage.
