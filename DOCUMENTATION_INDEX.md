## Quick Reference

### How to Deploy
```bash
cd frontend && npm run build
# Then deploy as usual
```

### How to Test Locally
```bash
cd frontend && npm start
# Visit http://localhost:5173
```

### How to Verify Changes
1. Search bar has green highlight
2. Product cards have shadows
3. Hover effects work smoothly
4. Checkout button is prominent
5. Mobile layout is responsive

### How to Rollback
```bash
git checkout frontend/src/SmallBasket.css
```
