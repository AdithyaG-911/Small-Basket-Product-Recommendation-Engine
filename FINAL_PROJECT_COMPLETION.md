### Color Palette
```
Primary Green:      #84c225 ← BigBasket signature
Secondary Green:    #689f38 ← Hover state
Accent Red:         #cc0000 ← Actions, cart
Dark Text:          #333333 ← Primary text
Light Text:         #999999 ← Secondary text
Light Background:   #f8f8f8 ← Surfaces
Border:             #e0e0e0 ← Subtle dividers
```

### Typography
```
Headlines (700):    28px / 24px / 18px
Body Text (400):    14px / 13px / 12px
Emphasis (600):     Medium weight
Font Family:        Montserrat, Helvetica, Arial

```
Base Unit:  8px
Common:     16px, 24px, 32px, 40px
Padding:    12px, 16px, 20px, 24px
Gaps:       16px, 24px, 32px
```

Medium:  0 4px 12px rgba(0,0,0,0.12)
Large:   0 8px 20px rgba(0,0,0,0.12)
```
